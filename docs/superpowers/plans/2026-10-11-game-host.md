# Game Host Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ascension serves its own web UI and API. Ember registers games by URL and plays them in an iframe.

**Architecture:** ember_api keeps a `games` registry and issues one-time launch tickets. The game redeems a ticket server-to-server and issues its own bearer session to its UI. ember_web becomes a generic `/games` host. ember_admin manages the registry.

**Tech Stack:** FastAPI, SQLAlchemy async + Alembic, httpx, pytest (ember_api, ascension); Vue 3 + TS + Pinia + Vite + Vitest (ember_web, ember_admin, ascension/web).

**Spec:** `docs/superpowers/specs/2026-10-11-game-host-design.md`

- Never read or print `.env*`, `secrets/` or key files. Do not enter tokens or passwords.
- Never launch browser-verification agents. The user tests by hand.
- Stage only your own files and hunks. Another session has uncommitted work in `ember_web` (`README.md` ticket hunk, `e2e/fakeApi.ts` tags hunk, `src/api/types.ts`, `CommandFormModal.*`, `MarkdownContent.vue`, `MessageList.vue`, `ToolRunForm.*`, `utils/toolSchema.ts`, `ChatView.vue`). Use `git apply --cached --unidiff-zero` with filtered patches for shared files.
- Never run git at the workspace root. Code repo is `MCPServer`.
- No literal `border-radius` values (use the radius tokens). Dot-prefixed means always ignored; tracked data gets plain names.
- Commit messages end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Commits and docs are normal prose.
- Skills: edit `.agents/skills/` only, then `python sync_skills.py`.
- Ticket lifetime 60 seconds, single use, stored as SHA-256 only. Game session token 256-bit random, in memory, expiring.
- Permission names: `games.<id>.play` per game, `games.manage` for the registry. `<id>` matches `^[a-z0-9][a-z0-9-]{0,62}$`.
- Game URLs: http or https only, no credentials, manifest fetch with timeout 5 s, size cap 64 KiB, no redirects.

## Deviations from the spec (found while planning)

1. **Permissions are a static dict today** (`ALL_PERMISSIONS`), checked in 8 places. Task 1 adds a small `PermissionCatalog` rule for the dynamic `games.<id>.play` names instead of a second permission system.
2. **A new static permission `games.manage`** guards register, refresh and deregister (the spec said "admin-only").
3. **CSP `frame-src` is static.** ember_web's CSP is a fixed header from `vite.config.ts` (`vite preview`). It cannot be built per request from the registry. Task 14 reads the allowed game origins from env `EMBER_GAME_ORIGINS` (default: loopback). `GameStage` additionally refuses any URL whose origin differs from the registered game's origin.

```python
class ManifestFetcher:
    def __init__(self, client, *, allow_private: bool, timeout: float = 5.0, max_bytes: int = 65536) -> None: ...

    async def fetch(self, base_url: str) -> Manifest:
        base = normalize_game_url(base_url, allow_private=self._allow_private)
        try:
            async with self._client.stream("GET", f"{base}/manifest.json", timeout=self._timeout) as response:
                if response.status_code != 200:
                    raise ManifestError(f"The game answered {response.status_code} for its manifest")
                body = bytearray()
                async for chunk in response.aiter_bytes():
                    body += chunk
                    if len(body) > self._max_bytes:
                        raise ManifestError("The manifest is too large")
        except (httpx.HTTPError, httpx.InvalidURL) as error:
            raise ManifestError("Cannot reach the game") from error
        return self._parse(bytes(body))
```

`_parse` loads JSON, requires an object, validates each field's type and length, and `re.fullmatch(GAME_ID_PATTERN, id)`. `normalize_game_url` uses `urllib.parse.urlsplit`, `ipaddress` for IP checks, and treats `localhost` and names ending `.localhost` as private.

```python
async def redeem(self, game_id: str, ticket: str) -> int | None:
    digest = hashlib.sha256(ticket.encode()).hexdigest()
    now = self._now()
    result = await self._session.execute(
        update(GameTicket)
        .where(GameTicket.token_hash == digest, GameTicket.game_id == game_id,
               GameTicket.used_at.is_(None), GameTicket.expires_at > now)
        .values(used_at=now)
    )
    await self._session.commit()
    if result.rowcount != 1:
        return None
    return await self._session.scalar(select(GameTicket.account_id).where(GameTicket.token_hash == digest))
```
