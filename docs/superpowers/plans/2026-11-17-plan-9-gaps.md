# Plan 9 gaps

Branch `feat/ember-gaps`. Closes what Plan 9 left open, except what needs Rust.

## Done
- **Dictation:** Portcullis `/api/attachments/dictate/stream` accepts a configured desktop origin and reads the session token from the subprotocol pair `ember.bearer, <token>` (no cookie is used from a desktop origin; the subprotocol is echoed so the browser accepts the socket). The app opens the socket with it. The Tauri CSP `connect-src` gained `ws: wss:`. Tests: 5 in `tests/test_dictation_stream.py`.
- **File links:** `saveFile()` in `src/utils/server.ts` fetches with the bearer and saves a blob; `DownloadCards` (chat cards, PDF merger, media downloader jobs and packages) and the media downloader `FileRow` use it. Tests in `server.test.ts`.
- **Shared-chat page:** `GET /shared/{token}` in Portcullis (`shares.page_router`): escaped read-only HTML, no script, its own CSP, `no-store`, `noindex`, same 404 and rate limit as the API read. Two tests.
- **Notifications:** the existing web `Notification` code runs in WebView2; no Tauri plugin added (it needs Rust to build). Documented.
- **Calendar view:** dropped, the calendar was removed from Citadel (Plan 11).

## Not done
- The Tauri shell is still uncompiled: Rust is not installed here. `Cargo.lock` is missing.
- No run in a window or against a live Portcullis, so WebView2's download prompt, notification permission and the dictation socket are unverified.
