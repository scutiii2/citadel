# Ascension ink-style type symbols

Created with built-in imagegen from the original type symbols and the user's talisman photograph as a drawing-style reference only. Output: six transparent PNG variants; original pixel-art symbols remain in the parent folder. No physical talismans or borders.

## pure

```text
Restyle the Ascension PURE symbol as ONE simple flat ornamental ink glyph.
Input image 1 is a STYLE REFERENCE ONLY: copy the drawing language of the colored animal marks INSIDE the talismans, never the physical talismans. Input image 2 is the original pure symbol: preserve its identifying motif, but radically simplify and flatten it.
Motif to retain: an upright pointed crystal with a single sweeping orbit; express facets with two or three transparent slits.
Target drawing language: stylized folk-art stencil, fluid calligraphic curves, broad tapered strokes, hooklike pointed tips, expressive asymmetry where appropriate, deliberate transparent negative-space gaps, elegant compact pictogram. Like the reference's simple painted animal silhouettes. One uniform solid cobalt blue ink color only; no outlines of another color.
Remove ALL pixel-art rendering, jewel ornaments, copper fittings, shaded facets, glows, gradients, textures, highlights, shadows, 3D volume and material rendering from input image 2. Make it feel like a clean single-color drawn mark, readable at 32 pixels, with approximately 4 to 8 bold shapes and broad negative spaces. Smooth curves and sharp tapered terminals. No simulated brush roughness or distressed surfaces.
CRITICAL: ONLY the flat glyph on a genuinely transparent background. NO talisman, stone, tile, medallion, octagon, disc, coin, plaque, physical object, border, enclosing frame or decorative badge. No background or photographed surface. No text, letters, labels, watermarks. The orbit/halo/core expressly required by the motif is part of the drawing, never an outer badge.
Square canvas 1024 x 1024. Centered symbol occupying about 70% of canvas; consistent visual scale and weight across a six-symbol set. Generous transparent margin. Preserve transparency. This is an edited variant; do not reproduce the original detailed pixel-art style.
Use case: style-transfer. Asset type: transparent single-color game type glyph.
```
